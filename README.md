# 🌲 Попаданец — Живой мир

> Ты не герой истории. Ты человек, который оказался внутри истории.
> Мир не ждёт тебя — он живёт своей жизнью.

Браузерная RPG-песочница про попаданца в аниме-мир. Играбельный **прототип v0.5-preview** по игровому паспорту (см. [`docs/PASSPORT.md`](docs/PASSPORT.md)): деревня, 20+ значимых NPC с расписаниями и портретами, свободный ввод, фракции и репутация, романтика, экономика с живыми ценами, пошаговый бой 8×8, память мира, канон с отклонениями, сюжетная линия разбойников, призраки прошлого в story-режиме, процедурное аудио, три режима смерти.

## Changelog

### v0.5-preview
- **Аудио (13)**: zero-dep WebAudio — процедурный эмбиент по регионам (деревня/лес/тракт/бой), птицы днём, погода в звуке, SFX (удары, криты, победа, квесты, ачивки, левелапы, шаги, монеты), включение по первому жесту, переключатель в настройках.
- **Фракции и репутация**: деревня / храм / торговый дом / лес (−100..100). Работа, сделки, молитвы, охота, дела меняют репутацию; эффекты: оплата ×1.2 (деревня ≥30), лечение молитвой (храм ≥15), реже зверь в лесу (лес ≥15), цены ±5% (торговля ≥20). Вкладка «Фракции» в журнале.
- **Романтика**: прогулки («прогуляться с Улой», 8:00–20:00) и признание в любви — Ула, Ханс, Каспар, Юстина; стадия «отношения» и ачивка «Не один в этом мире».
- **Сюжетная линия разбойников**: следы на южной дороге (осмотреть с 3-го дня) → доклад Каспару (нужны факты, не слухи) → канон меняется → окно засады 3 дня → бой с главарём и двумя подельниками → награда 150 м. + репутация.
- **Призрак прошлого** (story-режим): погибший персонаж становится NPC на опушке — расскажет, кто он и что помнит (важные события мира до его смерти).
- **Мелочи**: молитва/ярмарка/паломники как действия и кнопки, портреты шести ключевых NPC (AI-арты), жесты (свайп влево — меню, вправо — закрыть, лонг-тап по NPC — осмотр), trade-цены учитывают репутацию и скидку Эрика, награды квестов идут дарителю, доставка трав Грете закрывает квест.

### v0.1

## Онлайн-версия

Игра автоматически публикуется на GitHub Pages: **https://gremel222.github.io/Tick/**
Источник — папка `docs/` (Settings → Pages → Deploy from a branch → `/docs`).
Обновить статику после правок клиента:

```bash
./scripts/build-pages.sh   # копирует client/ → docs/ и делает 404.html = index.html
```

Базовый путь (`/Tick/`) вычисляется в рантайме (`client/src/base.js`), `404.html`
даёт SPA-фолбэк для прямых ссылок вида `/Tick/play`.

## Запуск

```bash
node server.js          # → http://localhost:3000
```

Ноль зависимостей: Node ≥ 18, любой браузер последних двух лет. Клиент — vanilla ES2022 без сборки (по паспорту: html5 + css3 + vanilla-js).

Тесты движка (без браузера):

```bash
node tests/sim.mjs        # смоук-прогон: парсер, диалоги, бой, канон, смерть, сюжетный режим
npm i jsdom --no-save
node tests/ui-smoke.mjs   # headless-прогон UI: лендинг → создание → игра → бой → смерть/загрузка
```

## Что внутри (соответствие паспорту)

| Раздел паспорта | Реализовано в v0.1-прототипе |
|---|---|
| 4.3 Время | 1 игровой день ≈ 15 реальных минут; действия тратят игровое время; оффлайн-докатка (1:1, макс. 7 дней) |
| 4.4 Смерть | normal / hardcore / story — мир в сюжетном режиме переживает персонажа |
| 4.6 Сохранения | snapshot, 5 слотов + автосейв (5 мин), экспорт/импорт JSON |
| 4.7 Управление | M/C/I/J/Q/Esc + Enter, мобильная раскладка, тапы |
| 4.8 Мир-тик | hybrid: пассивный тик (1 сек) + day-by-day перемотки |
| 4.9 Парсер | tokenize → classify → extract-slots → validate → execute, fallback — уточняющий вопрос |
| 4.10 Ачивки | 5 базовых, включая скрытую «Живая легенда» |
| 5 Мир | 10 локаций, 3 региона, 20 NPC с полными профилями и расписаниями, онбординг-неделя, открывающая сцена |
| 5.3 Канон | 6 канонических событий, статусы planned/happened/changed, счётчик отклонений |
| 6 UI | Все роуты из паспорта: лендинг, девлог, вики, рейтинг, юр-страницы, игра |
| 8 Аккаунты | Локальные аккаунты (в прототипе), GDPR-экспорт/удаление, куки-баннер, 16+ |
| 9 ИИ | Rules-first ядро диалогов (тон → фразы → темы → отношения). ИИ-fallback: точка подключения в `dialogue.js` |
| 10 Экономика | `base*(1+demand/supply)`, массовые закупки двигают цены, налоги 5%/10%, ежедневный дрейф |
| 11 Память мира | важное — навсегда, мелкое — 30 дней, свидетели, слухи с типами правдивости |
| 12 Бой | 8×8, инициатива по ловкости, урон `atk−def+roll(luck)`, криты, 4 профиля ИИ |

## Структура

```
client/
  index.html
  src/
    main.js            # роуты (6.1) + куки-баннер
    router.js  ui.js   # history-API роутер, модалки, тосты
    api/local.js       # локальные аккаунты (в полной версии — сервер)
    game/              # WORLD ENGINE — без DOM, тестируется в Node
      data.js          # мир, NPC, предметы, канон, квесты, тона реплик
      engine.js        # состояние, время, действия, отношения, квесты, смерть
      parser.js        # свободный ввод (4.9)
      dialogue.js      # rules-based диалоги (9)
      economy.js       # цены (10)
      combat.js        # бой (12)
      memory.js        # память мира + канон (11, 5.3)
      saves.js         # snapshot-сохранения (4.6)
    screens/           # лендинг, авторизация, создание, открытие, игра, публичные
    components/        # панели (карта/журнал/инвентарь), диалог, бой
server.js              # zero-dep статика + SPA-fallback
tests/sim.mjs          # смоук-прогон движка
docs/PASSPORT.md       # игровой паспорт v4.0
```

## Путь к полной версии (по паспорту)

Прототип сознательно обходит серверную часть: сохранения — localStorage, аккаунты — локальные, диалоги — rules-only. Точки роста размечены:

1. **Сервер** (7): Node 20 + Express + Prisma + PostgreSQL 16, JWT/argon2id — схема БД в приложении B паспорта.
2. **ИИ** (9): `dialogue.js` → вставка Anthropic SDK для roleplay-диалогов с zod-валидацией, кэш `npcId+intent+contextHash`, бюджет $0.05/игрок/день.
3. **Инфра** (7): Netlify (клиент) + VPS 2/4 (сервер), GitHub Actions, Sentry, UptimeRobot.
4. **Контент** (13): арты по иконкам-эмодзи → иллюстрации, i18n-файлы с первого дня.
