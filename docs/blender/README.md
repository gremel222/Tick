# Академия Blender

Офлайн-справочник и тренажёр по Blender на русском языке: **мгновенные ответы на вопросы
по всем ~4200 страницам руководства и справочника Python API**, рукописные уроки,
тренажёры горячих клавиш и интерфейса, карта знаний с интервальным повторением.

Работает без сервера и без интернета: вся база лежит в сжатых JSON-шардах,
поиск считается в браузере (BM25 + морфология RU + алиасы официального словаря).
Никакого ИИ и внешних API — ответ приходит за 8–100 мс и всегда со ссылкой на мануал.

## Быстрый старт

```bash
node blender/tools/serve.mjs        # http://localhost:4173/blender/
node blender/tools/test-search.mjs  # прогон поиска по 24 контрольным вопросам
node blender/tools/smoke.mjs        # проверка интерфейса без браузера (18 маршрутов)
```

## Что внутри

| Экран | Возможности |
|---|---|
| **Спросить** | поиск-ответчик: понимает «где…», «что делает…», «как включить…», названия опций, номера клавиш, опечатки; отвечает определением, шагами, клавишей и ссылками на источники |
| **Справочник** | 19 разделов, дерево страниц, полнотекстовый поиск по разделу, ссылки на официальный мануал |
| **Учить** | рукописный курс: модули с целями, разбором интерфейса, таблицами и заданиями |
| **Тренажёры** | 47 заданий на горячие клавиши, квиз, симулятор панелей интерфейса |
| **Прогресс** | достижения, серия дней, интервальное повторение (SM-2), экспорт/импорт прогресса |

Проверки: `node blender/tools/test-search.mjs` (поиск), `node blender/tools/smoke.mjs`
(рендер всех экранов на встроенном DOM-шиме), `node blender/tools/crawl-ru.mjs --selftest`
(парсер русских страниц).

Служебные URL приложения (хэш-роутер): `#/home`, `#/ask`, `#/ref`, `#/doc?p=...`,
`#/learn`, `#/lesson?m=...`, `#/train`, `#/trainer?kind=...`, `#/progress`, `#/about`.

## Архитектура

```
blender/
  index.html            оболочка + PWA-манифест
  sw.js                 офлайн-режим (оболочка — network-first, данные — stale-while-revalidate)
  icon.svg              иконка приложения
  src/
    app.js              роутер, оболочка, предзагрузка индекса
    lib/text.js         морфология RU, стемминг, канонизация клавиш, алиасы
    lib/search.js       BM25 + алиасы + якоря + клавиши + опечатки + автодополнение
    lib/answer.js       сборка ответа (клавиша → опция → страница → «не нашлось»)
    lib/data.js         загрузка и кэш шардов
    lib/store.js        прогресс, достижения, SM-2 (localStorage)
    screens/*.js        экраны приложения
  content/              рукописный контент: курс, задания, симулятор, синонимы
  tools/build-data.mjs  сборщик базы из vendor/manual + vendor/api + ru.po
  data/                 готовая база (шарды .json.gz) — коммитится
  vendor/               исходники мануала (не коммитится, качается скриптом)
```

## Русские тексты страниц (краулер)

Поиск и ответы работают сразу: английский исходник руководства сопоставляется с
официальным словарём интерфейса `ru.po`, поэтому русские вопросы находят нужные
опции и клавиши. Чтобы **читать** страницы по-русски, нужен разовый прогон краулера
(ему нужен доступ к `docs.blender.org` — из закрытых песочниц он недоступен):

```bash
node blender/tools/crawl-ru.mjs --section editors --limit 20 --dry   # проба
node blender/tools/crawl-ru.mjs                                     # всё руководство
node blender/tools/crawl-ru.mjs --selftest                          # проверка парсера без сети
```

Краулер аккуратен к серверу (4 потока, пауза 120 мс, докачка с места обрыва) и
складывает результат в `blender/data/ru/<раздел>.json.gz` — приложение подхватывает
эти шарды автоматически (в `meta.json` появляется `hasRu: true`), английский текст
остаётся запасным вариантом для непереведённых страниц.

**Автоматизация:** готовый workflow лежит в `blender/tools/crawl-ru.workflow.yml`.
Скопируйте его в `.github/workflows/crawl-blender-docs.yml` через веб-интерфейс
GitHub (Add file → Create new file) — дальше он запускается по кнопке и раз в месяц
по расписанию, сам коммитя обновлённые шарды.

## Обновление базы справочника

```bash
bash blender/tools/fetch-vendor.sh     # скачивает markdown-мануал, справочник API и ru.po
node blender/tools/build-data.mjs      # ~7 с: страницы, термины, алиасы, якоря, клавиши
node blender/tools/test-search.mjs     # контрольные вопросы
```

Сборщик строит:

* **страницы** — заголовок (RU + EN), резюме, блоки текста, шаги-инструкции;
* **термины** — пары EN↔RU из официального словаря интерфейса (`ru.po`, ~40 000 записей);
* **алиасы** — названия функций и опций из руководства (вес: заголовок 10, подзаголовок 8, определение 6);
* **якоря** — карточки «опция → что делает» с русским названием из словаря (39 570 шт.);
* **клавиши** — горячие клавиши из значков документации + рукописные задания (2049 шт.).

## Публикация

`bash scripts/build-pages.sh` копирует игру и академию в `docs/`, откуда GitHub Pages
раздаёт сайт: `https://gremel222.github.io/Tick/blender/`.
Пути внутри приложения относительные, поэтому адрес можно менять (в том числе
вложенный подкаталог) без пересборки.
