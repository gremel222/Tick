# Проверка главы перед сдачей

Сжатая версия общего чек-листа. Оставлено только то, что относится к русскому ЛитерРПГ-фику на Фикбуке. Отброшено как неприменимое: SEO, юридическое, доступность, монетизация, безопасность, локализация, метаданные.

**Прогонять после каждой главы. Найденное править, а не отмечать.**

---

## Приоритет 1 — ломает историю

Провал здесь = главу нельзя отдавать.

**Факты**
- [ ] Даты посчитаны, а не названы на глаз. Сверено с `bible.md` → «Сверенные числа».
- [ ] Возрасты персонажей соответствуют дате в мире.
- [ ] Все числа внутри главы бьются друг с другом.
- [ ] Медицина: симптомы, сроки, последствия — правдоподобны.
- [ ] Техника и быт соответствуют году действия (2005: бумажные карты, без смартфонов).
- [ ] США: документы, вывески, бланки — на английском, формат `MM/DD/YYYY`.

**Канон**
- [ ] Ничего из книг Л. Дж. Смит.
- [ ] Сверено с `canon/` по датам, местам, артефактам.
- [ ] Персонажи канона не знают того, чего не знали бы в этот момент.

**Кто что знает**
- [ ] Каждый факт в голове героя имеет видимый источник: браслет, карта, документ, реплика, егоOwn прошлая жизнь.
- [ ] Никаких имён и деталей «из воздуха». Если имени нет ни на одном носителе — он его не знает.
- [ ] Выводы героя показаны как выводы: из чего именно он их сделал.

**Логика**
- [ ] «А мог ли он это?» — физически, после травмы, с его состоянием.
- [ ] «А успел ли он?» — время сцены сходится.
- [ ] «А есть ли ресурсы?» — деньги, доступ, силы.
- [ ] Нет роялей: предмет, союзник, навык введены раньше, чем применены.
- [ ] У каждого события есть последствие в этой главе или в завязках `bible.md`.

## Приоритет 2 — ломает доверие к тексту

**Повторы** (главная болезнь)
- [ ] «Значит» — не чаще 2 раз на главу.
- [ ] Одно и то же слово-связка не стоит в начале соседних абзацев.
- [ ] Никакой конструкции больше 3 раз на главу, если только это не намеренный мотив.

**Стиль**
- [ ] Стоп-лист из `стиль.md` — ноль.
- [ ] Названных эмоций — ноль.
- [ ] Пассива вне окон Системы — ноль.
- [ ] Канцелярита вне окон Системы — ноль.
- [ ] Списков и итогов в прозе — ноль.
- [ ] Нет трёх предложений подряд одной длины.

**AI-маркеры**
- [ ] Нет: «важно отметить», «стоит подчеркнуть», «не только… но и», «с одной стороны», «таким образом», «подводя итог», «в конечном счёте», «играет важную роль».
- [ ] Нет симметричных абзацев одинаковой длины.
- [ ] Абзацы не выровнены «под линейку».

**Метафоры**
- [ ] Понял бы её собеседник? Соответствует эпохе?
- [ ] Из лексикона героя, а не из лексикона автора.

---

## Приоритет 3 — качество

**Композиция**
- [ ] «Что, если?» главы сформулировано одним предложением.
- [ ] В первом предложении ясно, где и когда.
- [ ] У сцены есть функция, она меняет ситуацию.
- [ ] Глава заканчивается на человеке, а не на окне, дате или событии.

**Диалог**
- [ ] У каждого участника своя цель.
- [ ] Реплика вытекает из предыдущей.
- [ ] Нет инфодампа: факты идут через карту, врача, документ, а не через «как ты знаешь».
- [ ] Голоса различаются без подписи.
- [ ] Нет «вот ты такой и есть» и аналогов.
- [ ] Персонажи замечают странности героя.

**Персонаж**
- [ ] Поступок объясним его целью, а не нуждами сюжета.
- [ ] Он не знает будущего наверняка — только вероятности.
- [ ] Слабости работают: удача 3, разум не защищён.

**Система**
- [ ] Окна дозированы по плану в `bible.md`.
- [ ] Система не шутит, не объясняет, не подсказывает.
- [ ] Канцелярит и пассив — только внутри окон.

## Что проверяется автоматически

Запускать после черновика:

```
grep -c "Значит"              # норма: <= 2
grep -o "слово" | sort | uniq -c   # на любое подозрительное слово
grep -E "стоп-лист"           # ноль
grep -E "(был|была|было) \w+(н|нн|т)(ый|ая|ое|ые)?"   # ноль
python3: распределение длин предложений  # ни одного провала
python3: частотность начал предложений  # «Я» не должно превышать ~25%
```

## Что делать с находкой

1. Нашёл повтор — замени, а не оставь «для ритма».
2. Нашёл незакрытую завязку — внеси в `bible.md`.
3. Нашёл факт без источника — либо дай источник в тексте, либо убери факт.
4. Нашёл логическую дыру — правь сцену, а не добавляй пояснение.

**Не применять к этому проекту:** SEO, разметка schema.org, AI-детекторы (не надёжны), юридические блоки, 152-ФЗ, доступность WCAG, локализация, метаданные, антиплагиат.
