# Фанфик: «Дневники вампира» — попаданчество + Система (the Gamer)

## Что решили с пользователем

| Параметр | Решение |
|---|---|
| **Герой** | Оригинальный персонаж (не канонное тело) |
| **Точка входа** | За несколько лет до 1-го сезона |
| **Тон** | Серьёзный, мрачный, расчётливый. Без четвёртой стены и без клоунады |
| **Романтика** | Елена Гилберт (медленно; до 17 лет Елене — только опека/дружба) |
| **Формат** | По одной главе за подход + обязательное обновление файла памяти |

## Процесс

- **`кратко.md`** — паспорт фика на одной странице: 7 блоков, тезисно, со статусами «готово / надо решить / оставляю загадкой». Главный файл для сверки.
- **`design.md`** — дизайн-документ: ответы на все вопросы по истории (герой, антагонист, конфликт, структура, тон, правила подачи). Основа, по которой пишутся главы.
- Главы: `chapters/chapter-NN.md`
- Память: `bible.md` — обновляется **после каждой главы** (состояние ГГ, статы, квесты, дата в мире, кто что знает, открытые завязки, список «не забыть»)
- Канон: `canon/*.md` — справочник, чтобы не ошибаться

## Рабочие установки (подтверждены)

1. **Старт — 21 августа 2005 года.** До начала канона (7 сентября 2009) — **1478 дней**. Счётчик показывается Системой.
2. **ГГ:** Артём Лавров, 24 года, аналитик из Владивостока; погибает в ДТП; приходит в себя в теле 18-летнего местного Артёма Лаврова, выпускника Mystic Falls High.
3. **Окружение:** мать — медсестра в больнице Мистик-Фоллс; сам — подсобник в Mystic Grill. Ни денег, ни связей, ни силы.
4. **Класс:** «Геймер (уникальный)» — окно статуса, Наблюдение, инвентарь, журнал квестов, магазин Системы, опыт за осмысленные действия.
5. **Главная слабость:** «Тело игрока» конвертирует физический урон в HP, но **разум не защищён** — гипноз вампиров, телепатия психиков и магия работают в полную силу. Удача на старте минимальна.
6. **Знание сюжета не абсолют:** «Журнал предсказаний» с процентом уверенности; чем сильнее вмешательство, тем быстрее предсказания устаревают.
7. **Валюта:** очки прокачки + **очки сюжета** (за сохранение/изменение ключевых событий канона).
8. **Тайна:** за Системой — «Арбитр» и «Договор» с неизвестной ценой. Длинная линия на всю историю.
9. **Возраст Елены:** в 2005-м ей 13. Никакой романтики до 17 лет.
